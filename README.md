# Superstore Sales & Profit Analysis Dashboard

## Project Overview
This project uses Tableau to analyse Superstore retail sales and profitability. The interactive dashboard helps users understand sales performance, compare profits across product categories, and evaluate profit margins across different regions.

## Objectives
- Analyse total sales and total profit.
- Compare sales performance across Furniture, Office Supplies, and Technology.
- Evaluate profit margins by product category.
- Enable interactive regional analysis using filters.
- Present key business metrics through a clear, interactive dashboard.

## Tools & Technologies
- **Tableau Desktop** — dashboard creation and data visualisation
- **Superstore Dataset** — retail sales and profit analysis
- **Calculated Fields** — profit margin calculation
- **Interactive Filters** — regional exploration

## Dashboard Features
1. **Total Sales KPI:** ₹972,185.79
2. **Total Profit KPI:** ₹227,622.79
3. **Overall Profit Margin KPI:** 23.41%
4. **Sales Performance:** Compares sales across product categories.
5. **Profitability Analysis:** Compares total profit across categories.
6. **Category Insights:** Compares profit margins across categories.
7. **Region Filter:** Allows users to explore results by region.

## Key Findings
- **Technology** has the highest sales and total profit among the three product categories.
- **Office Supplies** has the highest profit margin at 24.44%.
- **Furniture** has the lowest profit margin at 21.72%.
- The overall profit margin is approximately 23.41%.

## How to Use
1. Download or clone this repository.
2. Open the packaged Tableau workbook (`.twbx`) using Tableau Desktop.
3. Open the dashboard and use the Region filter to explore the data.
4. Review sales, profit, and profit-margin trends by category.
